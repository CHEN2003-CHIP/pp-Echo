# 00 Vision

## 项目定位

pp-Echo 是一个面向个人开发者和小团队的本地优先 Coding Agent 与通用助手。它的目标是帮助用户管理中小型代码项目，完成代码理解、修改、测试、总结和三方工具操作。

## 核心目标

- 让 AI 能安全理解一个代码仓库。
- 让 AI 能按 Mission -> Task -> Check 小步改代码。
- 让文件编辑、测试、反馈、总结形成闭环。
- 让工具、插件、MCP 和外部 API 逐步接入，但不破坏 runtime 边界。
- 让用户始终能审查 AI 做了什么、为什么做、还有什么风险。

## 目标用户

- Solo developer。
- 小团队技术负责人。
- 希望用 AI 管理中小型代码项目的人。
- 想保留本地控制权、审计记录和安全边界的开发者。

## 当前阶段

当前是从学习型 Agent 项目进入产品化推进的准备期。

本阶段优先建立 Solo AI-native 工作流，不优先开发新 Agent 功能。

## 非目标

- 不做重型企业项目管理系统。
- 不做复杂多 Agent 平台。
- 不优先做大型 UI。
- 不追求一次性接入所有外部系统。
- 不牺牲安全边界换取演示速度。

## 成功标准

- 用户可以用 BOARD、Mission、Roadmap 和 Release Log 持续推进项目。
- 每次 AI 协作任务都有明确边界、验收和人工确认点。
- 项目能从文档治理自然过渡到安全文件编辑、测试反馈和 Coding Agent MVP。
- 重要决策和风险能被记录，而不是散落在聊天记录里。
