# Experiment Report Style Guide

## Writing style

- Use concrete descriptions instead of empty praise.
- Avoid long and complicated sentences.
- Use data to support conclusions.
- Mention figure and table numbers when discussing results.
- State missing information clearly.

## Figure style

- Use readable axis labels.
- Include units when available.
- Use a descriptive title or caption.
- Do not use low-resolution screenshots when clean data plots are available.
- Prefer one clear chart over multiple redundant charts.

## Table style

- Keep tables compact.
- Use consistent units.
- Round numbers consistently.
- Put table titles above tables.

## Chinese report defaults

- A4 portrait.
- Clear numbered headings.
- Body text should be concise and formal.
- Figure captions go below figures.
- Table captions go above tables.
