# Missing Information Policy

When important information is missing, do not fabricate it.

Use one of the following approaches:

1. If the missing information is not critical, mark it as "not provided" and continue.
2. If the missing information can be inferred from logs or screenshots, state the source of the inference.
3. If the missing information prevents completing a required calculation, explain what is missing and provide the closest available analysis.
4. If the user explicitly asks for a final report, complete the report with transparent limitations rather than stopping.

Example wording:

```text
The provided materials do not include explicit CPU and GPU model information. Therefore, this report records the software commands and data files that are available, while marking hardware details as not provided.
```
