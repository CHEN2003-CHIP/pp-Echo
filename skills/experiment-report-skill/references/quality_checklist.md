# Quality Checklist

## Requirement coverage

- [ ] All required experiment tasks are covered.
- [ ] Bonus tasks are clearly separated from required tasks when applicable.
- [ ] Required sections are present.
- [ ] Required figures or tables are present.

## Evidence quality

- [ ] Results are derived from provided CSV, logs, screenshots, or code.
- [ ] No fabricated data is introduced.
- [ ] Missing data is explicitly marked.
- [ ] Analysis references specific figures, tables, or log evidence.

## Data analysis

- [ ] Repeated runs are averaged when appropriate.
- [ ] Speedup is computed only when baseline and optimized results are available.
- [ ] Units are preserved.
- [ ] Outliers or abnormal runs are mentioned when visible.

## Formatting

- [ ] A4 portrait if required.
- [ ] Heading levels are consistent.
- [ ] Figure numbers are continuous.
- [ ] Table numbers are continuous.
- [ ] Images are not distorted.
- [ ] No large blank pages.

## Final delivery

- [ ] DOCX opens correctly.
- [ ] PDF opens correctly if generated.
- [ ] Supporting figures are included.
- [ ] Editable diagrams are included when requested.
- [ ] Final response lists all artifacts.
