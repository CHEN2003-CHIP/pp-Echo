# pp-Echo v0.2.0

## Highlights

- Added a clearer planner / executor split so the agent can explain intended steps before acting.
- Expanded approval-first workflows for risky shell commands and file mutations.
- Strengthened session-tree navigation so branches, resume flows, and turn history are easier to inspect.
- Added git-backed checkpoint and safe rewind workflows for restoring code, conversation, or both together.
- Unified capabilities around builtin tools, skills, extensions, and MCP-backed discovery.

## CLI Changes

- `chat` remains the primary interactive entrypoint for repo-aware agent work.
- `run` supports single-shot prompts for fast automation and smoke testing.
- `sessions`, `approvals`, `checkpoint`, `capabilities`, and `skills` commands now form the core operational surface.
- `rewind-safe` exposes recovery workflows directly from the CLI.

## Breaking Or Migration Notes

- None.
