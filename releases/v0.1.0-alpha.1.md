# pp-Echo v0.1.0-alpha.1

pp-Echo v0.1.0-alpha.1 is the first preview release of a teaching-oriented local Agent Runtime.

It focuses on making the engineering mechanisms behind a Claude Code / Cursor-style local coding agent visible and learnable, including tool calling, approval, checkpoint/rewind, memory, MCP, subagents, eval, trace observability, and startup onboarding.

## Highlights

- Teaching-oriented local Agent Runtime.
- Mini pp-Echo learning path.
- Full AgentRuntime / ToolRegistry / Approval / Checkpoint / Memory / MCP / SubAgent workflow.
- Web UI and CLI workflow.
- Startup Guide via the upper-left pp-Echo button.
- CLI onboard command for first-time setup.
- TraceInspect for structured Agent runtime audit.
- LLM token / latency / retry / optional cost tracing.
- ToolRegistry middleware tracing.
- Deterministic eval suite for regression testing.
- Safety-first approval and checkpoint workflow.

## Quick Start

```powershell
git clone https://github.com/CHEN2003-CHIP/pp-Echo.git
cd pp-Echo

python -m venv .venv
.\.venv\Scripts\activate

python -m pip install --upgrade pip setuptools wheel
python -m pip install -e .[web]

set PYTHONPATH=src
set PP_AGENT_API_KEY=your_api_key

python -m pp_agent.cli.main onboard
.\start-web.bat
```

Open:

```text
http://127.0.0.1:8765
```

Click the `pp-Echo` button in the upper-left corner to open Startup Guide.

## Eval

```powershell
set PYTHONPATH=src
python -m pp_agent.cli.main eval run --suite pp_echo_core --mode deterministic --cases 100
python -m pp_agent.cli.main eval report
```

## Safety Notes

pp-Echo provides visible planning, approval gates, effect previews, checkpoint/rewind, and trace auditing.

It is not a full system-level sandbox. Use it as a learning, research, and engineering exploration project, not as a production coding agent replacement.

## Known Limitations

- Windows-first local workflow.
- Shell execution is controlled by policy and approval, but not fully sandboxed.
- LLM cost estimation depends on provider usage metadata and optional pricing configuration.
- Official provider billing integration is not included in this release.
- Some advanced plugin / skill packaging workflows are still evolving.
